# کتاب‌خانهٔ من — Library Studio v2

نسخهٔ موازی و بازطراحی‌شدهٔ مدیریت کتابخانهٔ شخصی با تمرکز بر تجربهٔ کاربری فارسی (`RTL`)، تقویم جلالی، جستجوی هوشمند فارسی، نقشهٔ فیزیکی کمدها و قفسه‌ها، آمار تحلیلی و مرکز سلامت داده‌های اکسل — با حفظ سازگاری کامل با `data/Books_v2.xlsx` و پشتیبانی از زبان انگلیسی.

---

## پیش‌نیازها

- Python 3.10+ (آزمایش‌شده روی Python 3.14)
- بسته‌های لازم:

```powershell
pip install pandas openpyxl rapidfuzz
```

---

## اجرای برنامه

از ریشهٔ مخزن (`d:\LibraryManager`):

```powershell
python library_v2/run.py
```

یا از داخل همین پوشه (`d:\LibraryManager\library_v2`):

```powershell
python run.py
```

### گزینه‌های اجرایی (`CLI`)
- `--data path/to/Books_v2.xlsx` : مسیر فایل اکسل دلخواه (پیش‌فرض: `data/Books_v2.xlsx`)
- `--port 8765` : پورت سرور محلی (در صورت اشغال بودن، پورت آزاد بعدی انتخاب می‌شود)
- `--host 127.0.0.1` : هاست سرور
- `--browser-mode app|tab` : اجرا به‌صورت پنجرهٔ مستقل دسکتاپ (`app`) یا تب مرورگر (`tab`)
- `--no-browser` : اجرای سرور بدون باز کردن خودکار مرورگر

مثال اجرای آزمایشی با تب مرورگر و فایل کپی‌شده:

```powershell
python library_v2/run.py --data data/Books_copy.xlsx --port 8780 --browser-mode tab
```

## امکانات کلیدی برای کاربر فارسی
- **نمای راست‌به‌چپ واقعی (`RTL`) و دوزبانه (`fa` / `en`)** با تغییر آنی جهت صفحه و تبدیل ارقام.
- **تقویم جلالی (شمسی):** نمایش تاریخ‌های ثبت و پایان مطالعه به شمسی در محیط فارسی و پشتیبانی از هر دو فرمت شمسی (`۱۴۰۵/۰۸/۲۱`) و میلادی (`2026-11-12`) در فرم‌ها.
- **جستجوی هوشمند فارسی:** پشتیبانی از `ي`/`ی` و `ك`/`ک` عربی، نیم‌فاصله (`جامعه‌شناسی` / `جامعه شناسی` / `جامعهشناسی`)، ارقام فارسی/لاتین، شناسه کتاب و جستجوی فازی (`rapidfuzz`).
- **نقشهٔ فیزیکی قفسه‌ها:** مرور بصری کمد ← طبقه ← ردیف و ثبت مستقیم کتاب در هر جایگاه.
- **مرکز سلامت داده‌ها:** کشف و اصلاح خودکار حروف عربی، فاصله‌های اضافی و وضعیت‌های ناهماهنگ با پشتیبان‌گیری خودکار در `data/backups/`.
- **خروجی سازگار با اکسل ویندوز:** خروجی `CSV` با `UTF-8 BOM` و دانلود مستقیم فایل `XLSX`.
