# 📚 مدیریت کتابخانه شخصی (`LibraryManager`)

این مخزن شامل دو نسخهٔ موازی برای مدیریت کتابخانهٔ شخصی مبتنی بر فایل اکسل (`data/Books_v2.xlsx`) است:

1. **`library_v2/` (پیشنهادی — استودیو مدیریت کتابخانه):** رابط کاربری مدرن، فارسی‌محور (`RTL`) و دوزبانه (`فارسی` پیش‌فرض + `English`) با سرور محلی پایتون، تقویم شمسی (جلالی)، جستجوی هوشمند فارسی، نقشهٔ فیزیکی کمدها و قفسه‌ها، آمار تحلیلی، مرکز سلامت داده‌ها و پشتیبان‌گیری خودکار.
2. **`src/` (نسخهٔ اولیه):** رابط دسکتاپی مینیمال با `Tkinter`.

---

## پیش‌نیازها

- **Python 3.10+** (روی **Python 3.14** آزمایش شده است)
- کتابخانه‌های اصلی:
  - `pandas`
  - `openpyxl`
  - `rapidfuzz`

در صورت نیاز به نصب کتابخانه‌ها:

```powershell
pip install pandas openpyxl rapidfuzz
```

*(اختیاری برای اجرای تست‌های رابط کاربری مرورگر و تحلیل کد: `playwright`، `ruff`، `mypy`)*

## راهنمای سریع اجرا (`library_v2`)

از پوشهٔ اصلی پروژه (`d:\LibraryManager`) دستور زیر را اجرا کنید:

```powershell
python library_v2/run.py
```

با اجرای این دستور:
- سرور محلی روی `http://127.0.0.1:8765/` بالا می‌آید (اگر پورت مشغول باشد، به‌صورت خودکار پورت آزاد بعدی انتخاب می‌شود).
- در ویندوز، برنامه به‌صورت خودکار در یک پنجرهٔ مستقل دسکتاپ (`Microsoft Edge` یا `Chrome` در حالت `--app`) باز می‌شود و مستقیماً به `data/Books_v2.xlsx` متصل است.

### گزینه‌های خط فرمان (`CLI`)

| گزینه | توضیح | مثال |
|---|---|---|
| `--data` | مسیر دلخواه فایل اکسل (پیش‌فرض: `data/Books_v2.xlsx`) | `python library_v2/run.py --data data/Books_test.xlsx` |
| `--port` | شماره پورت سرور محلی (پیش‌فرض: `8765`) | `python library_v2/run.py --port 9000` |
| `--host` | آدرس شبکه برای بایند شدن (پیش‌فرض: `127.0.0.1`) | `python library_v2/run.py --host 127.0.0.1` |
| `--browser-mode` | باز شدن به‌صورت پنجرهٔ مستقل (`app`) یا تب معمولی مرورگر (`tab`) | `python library_v2/run.py --browser-mode tab` |
| `--no-browser` | اجرای سرور بدون باز کردن خودکار مرورگر | `python library_v2/run.py --no-browser` |

برای دیدن همهٔ گزینه‌ها:

```powershell
python library_v2/run.py --help
```

برای متوقف کردن سرور در ترمینال از `Ctrl + C` استفاده کنید.

## بخش‌های اصلی برنامهٔ جدید (`library_v2`)

- **📚 کتابخانه:** جستجوی لحظه‌ای فارسی (حساس‌نبودن به `ي`/`ی` و `ك`/`ک`، نیم‌فاصله، ارقام فارسی/لاتین و خطاهای تایپی)، فیلتر پویا بر اساس کمد/قفسه، طبقه، ردیف، موضوع، وضعیت و امتیاز، نمایش جدولی و کارتی (با جلد آپلودی یا جلد طراحی‌شدهٔ خودکار)، و پنل کشویی جزئیات با تغییر سریع وضعیت و ستاره.
- **🗄️ نقشهٔ قفسه‌ها:** مشاهدهٔ فیزیکی تمام کمدها و قفسه‌ها به تفکیک **طبقه** و **ردیف**؛ با کلیک روی هر خانه می‌توانید کتاب‌های آن بخش را ببینید یا مستقیماً کتاب جدید در همان جایگاه ثبت کنید.
- **📊 آمار و تحلیل:** شاخص‌های مطالعه، درصد اتمام، میانگین امتیاز و نمودارهای توزیع وضعیت، قفسه‌ها، موضوعات و امتیازها.
- **🧹 سلامت داده‌ها:** شناسایی حروف عربی (`ي`/`ك`)، فاصله‌های اضافه، ناهماهنگی وضعیت‌ها (`finished` → `Finished`)، موارد بدون نویسنده یا بدون طبقه/ردیف و کتاب‌های تکراری؛ همراه با پاکسازی خودکار و امن.
- **🛡️ ایمنی داده و پشتیبان‌ها:** پیش از هر افزودن، ویرایش، حذف یا پاکسازی، یک نسخهٔ پشتیبان زمان‌دار به‌صورت خودکار در `data/backups/` ذخیره می‌شود و فایل اکسل به‌شکل اتمیک بازنویسی می‌گردد.
- **🌐 دوزبانه و تم:** با دکمه‌های بالای صفحه می‌توانید زبان را بین **فارسی (`RTL`)** و **English (`LTR`)** و ظاهر را بین **حالت روز** و **حالت شب** جابه‌جا کنید.
- **⌨️ میانبرهای صفحه‌کلید:** `Ctrl + K` برای رفتن سریع به کادر جستجو و `Esc` برای بستن پنجره‌ها و پنل جزئیات.
- **📅 فرمت تاریخ در فرم‌ها:** می‌توانید تاریخ را هم به‌صورت **شمسی** (مثلاً `۱۴۰۵/۰۸/۲۱`) و هم **میلادی** (`2026-11-12`) وارد کنید؛ در فایل اکسل برای سازگاری کامل به فرمت استاندارد `YYYY-MM-DD` ذخیره می‌شود.

## ساختار پوشه‌ها

```text
LibraryManager/
├── data/
│   ├── Books_v2.xlsx          # فایل اصلی کتاب‌ها
│   ├── backups/               # نسخه‌های پشتیبان خودکار (هنگام تغییرات ساخته می‌شود)
│   ├── covers/                # تصاویر جلد کتاب‌ها (هنگام آپلود ساخته می‌شود)
│   └── migrate_library.py     # اسکریپت مهاجرت نسخهٔ ۱ به ۲
├── library_v2/                # پروژهٔ جدید موازی (Library Studio v2)
│   ├── run.py                 # نقطهٔ ورود و راه‌انداز سرور/مرورگر
│   ├── README.md              # مستندات اختصاصی نسخهٔ جدید
│   ├── library_app/           # هستهٔ بک‌اند، سرویس‌ها، i18n و فایل‌های استاتیک وب
│   └── tests/                 # تست‌های واحد، API و تست سرتاسری مرورگر (Playwright)
└── src/                       # نسخهٔ قدیمی‌تر Tkinter
    └── main.py
```

در صورت تمایل به اجرای رابط قدیمی `Tkinter`:

```powershell
python src/main.py
```

## اجرای تست‌ها و بررسی کیفیت کد

تمام تست‌ها روی کپی موقت و ایزوله اجرا می‌شوند و تغییری در فایل اصلی `data/Books_v2.xlsx` ایجاد نمی‌کنند:

```powershell
python -m unittest discover -s library_v2/tests -v
```

بررسی لینتر و تایپ‌چک (در صورت نصب بودن `ruff` و `mypy`):

```powershell
python -m ruff check library_v2
python -m mypy library_v2/library_app library_v2/run.py --ignore-missing-imports
```

## رفع مشکلات رایج

- **خطای «فایل اکسل در برنامهٔ دیگری باز است»:** اگر `Books_v2.xlsx` هم‌زمان در `Microsoft Excel` باز باشد، سیستم‌عامل اجازهٔ بازنویسی فایل را نمی‌دهد. کافی است فایل را در اکسل ببندید و دوباره ذخیره را بزنید.
- **باز نشدن خودکار مرورگر یا پنجره:** برنامه را با `--no-browser` اجرا کنید و آدرس نمایش‌داده‌شده در ترمینال (معمولاً `http://127.0.0.1:8765/`) را در مرورگر باز کنید.
- **خروجی CSV فارسی در اکسل:** فایل CSV خروجی با کدگذاری `UTF-8 BOM` تولید می‌شود تا هنگام باز کردن مستقیم در اکسل ویندوز، حروف فارسی به‌هم نریزد.
